# User flows

## Quick capture

1. The app opens to **Brzi unos**.
2. The user taps `+`, enters one item, and saves it.
3. The app saves that item as a separate entry in **Nesortirano**.
4. The user can repeat this for the next item without choosing a space or type.

The user may optionally add details, including a date or a space, before
saving. This is an optional shortcut, not a different capture flow.

Examples: `mlijeko`, `kafa`, `rođendan Novak`.

## Organising an item

From Nesortirano, the user can open an item, add details, then either:

- move it to an existing space;
- create a new space and move it there; or
- keep it independent.

All saved items remain editable. An item can be changed completely and moved
between spaces later.

An item leaves Nesortirano automatically when it is assigned to a space. A
date alone does not remove it from Nesortirano, but makes it visible in the
global calendar.

A date without time creates an all-day calendar item. If the user chooses a
time, it ranges from `00:00:00` (midnight) through `23:59:59`. The user can
optionally set reminders for any dated item. A reminder configuration contains
at least one user-chosen date and time and can contain any number of them.
It may repeat on consecutive days, a selected weekday, or a selected day of
the month, until the user edits or disables it.
